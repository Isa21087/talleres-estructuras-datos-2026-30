# Árbol Binario

Esta carpeta contiene la implementación general de Árbol Binario construida a partir de la implementación trabajada con los videos y lineamientos del profesor.

La plantilla conserva la interfaz usada en esa implementación:

- `NodoBinario`
- `ArbolBinario`
- búsqueda y eliminación recursivas desde el nodo
- recorridos preorden, inorden, posorden y por niveles

## Uso posterior

Esta implementación se conserva como plantilla general.

Cuando un taller o proyecto necesite utilizarla, se realizará una copia y los cambios específicos se harán sobre esa copia, conservando intacta esta carpeta.

## Nota sobre la inserción

Este árbol binario no es ordenado. Por eso no utiliza comparaciones de menor o mayor para decidir el lado.

La implementación busca el nodo padre indicado y utiliza primero el espacio izquierdo y después el derecho. Esta es la forma conservada de la implementación base trabajada para la materia.
