# Árbol General

Esta carpeta contiene la implementación de Árbol General desarrollada durante las clases de Estructuras de Datos.

Actualmente se trabajará con:

- NodoGeneral
- ArbolGeneral

La implementación se desarrollará progresivamente siguiendo las indicaciones del profesor, las diapositivas y los recursos proporcionados durante la materia.

## Uso posterior

Esta implementación se conservará como plantilla.

Si posteriormente se trabaja una nueva estructura a partir de esta implementación, se realizará una copia y los cambios se harán sobre la nueva carpeta, conservando intacta la implementación de Árbol General.

Cuando un taller necesite utilizar esta estructura, se copiará la implementación correspondiente dentro del taller y las modificaciones específicas del ejercicio se realizarán sobre esa copia.
