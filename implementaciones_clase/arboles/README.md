# Implementaciones de Árboles

Esta carpeta contiene las implementaciones de estructuras de árboles desarrolladas progresivamente durante las clases de Estructuras de Datos.

Estas implementaciones se conservan como plantillas de trabajo que podrán reutilizarse posteriormente en los talleres que las necesiten.

## Fuentes de referencia

Las implementaciones deben seguir principalmente:

1. Indicaciones y código mostrado por el profesor.
2. Diapositivas de la asignatura.
3. Listas de reproducción y recursos proporcionados por el profesor.
4. Decisiones e implementaciones realizadas por el equipo.
